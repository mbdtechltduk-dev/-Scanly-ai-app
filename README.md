## Overview

A feature-rich mobile PDF toolkit built with Flutter,
combining document scanning, PDF creation, editing,
OCR, file organization and document management.

The application provides a dark-themed interface with
a tools dashboard, document library, editor utilities
and premium capabilities.

## Main Features

### PDF Creation & Scanning
- Document scanning to PDF
- Images to PDF
- Import existing PDF documents
- Create and manage PDF files

### PDF Editing
- Add signatures
- Add text
- Annotate documents
- Add watermarks
- Redact sensitive content

### PDF Optimization & Security
- Compress PDF
- Password-protect PDF documents

### PDF Organization
- Merge PDF documents
- Split PDF documents
- Organize pages
- Rotate pages
- Extract pages
- Delete pages

### OCR & Text Tools
- OCR text recognition
- Extract text from documents
- Search text inside documents

### Document Management
- Document library
- Folder organization
- Search documents
- Favorites and recent documents
- PDF and image filters

### User Experience
- Modern dark-themed interface
- Mobile-first responsive layouts
- Dashboard and categorized tools
- Files, Tools and Settings navigation
- Premium feature indicators
- Subscription upgrade interface
